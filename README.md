# Dungeon & Stone: Barbarian Survival

เกมแนว **Hardcore Roguelike / Dungeon Crawler** ภาษาไทยบนเว็บในธีม **Classic Grimoire (`100vh` locked viewport)** ที่ได้รับแรงบันดาลใจจากโลกของ *Dungeon & Stone* — เอาชีวิตรอดในเขาวงกตที่เปิดเดือนละ 7 วัน รวบรวมแก่นแท้ (Essence) บริหารภาษีและทรัพยากรในเมืองลาฟโดเนีย (Lafdonia) และเมืองใต้ดินโนอาร์ค (Noark)

---

## จุดเด่นและระบบการเล่นหลัก

### 1. โหมดการเล่นและ 6 เผ่าพันธุ์
- **Story Mode**: รับบทเป็น **Bjorn Yandel** (เผ่า Barbarian) ตามเส้นเรื่องหลัก
- **Custom Race**: ตั้งชื่อและเลือกเล่นได้จากทั้ง **6 เผ่าพันธุ์**:
  - `Barbarian` (คนเถื่อน)
  - `Human` (มนุษย์)
  - `Beastman` (ครึ่งสัตว์)
  - `Dwarf` (คนแคระ)
  - `Elf` (เอลฟ์)
  - `Dragonkin` (มังกร/ดราก้อนคิน)
- แต่ละเผ่ามีค่าพลังพื้นฐาน **สกิลประจำเผ่า (`1`)** และเรทราคาซื้อขายกับพ่อค้าในลาฟโดเนียที่แตกต่างกัน

### 2. เขาวงกต 7 ชั้น + 3 รอยแยก + ดันเจี้ยนลับ [วิหารร้อยสี]
- **Fog of War & ระยะมองเห็น**: คำนวณระยะการมองเห็นจาก Vision และการใช้คบไฟ (`Torch`)
- **วงจรเวลาและกฎเอาชีวิตรอด**: เขาวงกตเปิด **7 วัน** และปิด **21 วัน** มีระบบภาษีราชวงศ์, ความกระหายน้ำ/เสบียง (`Thirst`), น้ำหนักบรรทุก, คำสาป (`Curse`), ความทนทานเกราะ และระบบ **Permadeath**
- **รอยแยกมิติ (`Rifts`)**: ได้แก่ `Vampire Rift`, `Glacial Cave` (ถ้ำธารน้ำแข็ง) และ `Witch Forest` (ป่าแม่มด)
- **ดันเจี้ยนลับ [วิหารร้อยสี] (`Temple of 100 Colors`)**: ปลดล็อกเมื่อถึงชั้นที่ 4 หรือ Explorer Rank 6 ใช้ **2 Rift Stone** หรือ **120 Gold** ในการเปิดทางเข้า

### 3. ระบบแก่นแท้ (33 Essences), Synergy และสารานุกรมแก่นแท้
- **33 แก่นแท้**: มาพร้อมทั้งค่าสถานะ Passive, สกิล Active (`2–5`) และ **ข้อเสีย/ผลข้างเคียง (Drawbacks)** เพื่อความสมดุล พร้อมโบนัสสาย **Synergy** เมื่อสะสมครบชุด
- การจัดการแก่นแท้ที่ดรอป: ดูดซับเข้าตัวเอง, แบ่งให้เพื่อนร่วมทีมดูดซับ หรือบรรจุลงหลอดทดลอง (`Essence Vial`) เพื่อนำไปขาย/ประมูล (+35% Gold)
- **สารานุกรมแก่นแท้ (Essence Codex)** แบ่งระดับข้อมูลเป็น 4 ขั้น:
  1. `ไม่รู้ข้อมูล`
  2. `ข่าวลือ (ไม่ชัวร์)` จากการสืบข่าวในร้านเหล้า
  3. `ยืนยันโดยกิลด์` จากการซื้อตำรากิลด์
  4. `ยืนยันแล้ว 100%` เมื่อได้ครอบครองหรือดูดซับจริง

### 4. เมืองลาฟโดเนีย (Lafdonia) & เมืองใต้ดินโนอาร์ค (Noark)
- **แรงค์นักสำรวจ (`Rank 9 → Rank 5`)**: พร้อมกฎกิลด์ **Rank 6+** ที่ต้องลงทะเบียนแก่นแท้ที่ใช้งาน
- **ธนาคารและสินเชื่อ**: กู้ยืมเงินทุนสำรวจ (เผ่า Elf/Fairy ได้สิทธิ์ดอกเบี้ย `0%`)
- **โรงแรม & ร้านเหล้า**: พักค้างคืนเพื่อข้ามวัน/ฟื้นฟูพลัง ฟังข่าวลือประจำวันฟรี หรือสั่งเครื่องดื่มสืบข่าวแก่นแท้
- **ตลาด & โรงประมูล & คลังวัตถุโบราณ**:
  - ร้านค้าอุปกรณ์/เสบียง และโรงประมูลแก่นแท้ (+35% Gold)
  - ตลาดมืด **โนอาร์ค** พร้อมจำหน่ายไอเทมตัวเลข (`Number Items`) และเหตุการณ์ **สงครามโนอาร์ค**
  - คลังวัตถุโบราณและอาวุธปราบวิญญาณที่ใช้ **Rift Stone** (`idium_mace`, `wyvern_boots`, `pain_stone_relic`, `underworld_lantern`)

### 5. ปาร์ตี้เพื่อนร่วมทีมเนื้อเรื่อง 8 คน & ระบบ Trust / Awaken
- **ตัวละครหลัก 8 คน**: Erwen, Misha, Murad, Mage, Ainar, Dwalki, Amelia และ Raven ผสมกับ **นักสำรวจรับจ้างแบบสุ่มรายวัน** (จ้างได้สูงสุด 2 คนต่อปาร์ตี้)
- **กลยุทธ์ปาร์ตี้ (`Party Tactic`)**: ปรับแผนได้ระหว่าง `บุก (+25% ดาเมจเพื่อน)`, `สมดุล` และ `ป้องกัน (-15% ดาเมจเข้าแทงค์)`
- **ความเชื่อใจ (`Trust`) & ปลุกพลัง (`Awaken`)**: เพิ่มค่า Trust จากการพาเพื่อนร่วมทีมกลับเมืองอย่างปลอดภัย (+20) หรือมอบแก่นแท้ให้ดูดซับ (+25) เมื่อ Trust ถึง `60` สามารถปลุกพลังเพิ่มค่าสถานะและบัฟพิเศษให้ทีมได้

### 6. ระบบ Weapon Mastery, ท่าอาวุธ และศัตรูสายวิญญาณ
- เก็บค่าประสบการณ์ความชำนาญอาวุธ (`Weapon Mastery`) จากการกำจัดศัตรูในเขาวงกต
- ท่าอาวุธใน Hotbar: **กระโดด (`5 MP`)**, **สวิง (`7 MP`)** และ **บล็อก (`4 MP`)**
- ศัตรูสายวิญญาณ (`isSpirit`) จะลดทอนความเสียหายกายภาพลงหากผู้เล่นไม่มีอาวุธหรือไอเทมที่มีคุณสมบัติเจาะวิญญาณ (`piercesSpirit`)

### 7. ฉากจบ Victory, ระบบ New Game+ และ Save 3 ช่อง (`S1–S3`)
- พิชิตบอสท้ายเกมในวิหารร้อยสีเพื่อปลดล็อกหน้าจอฉากจบ **Victory** และเปิดใช้งาน **`[เศษเสี้ยวแห่งบันทึก]` (NG+)** ซึ่งเพิ่มความแข็งแกร่งให้มอนสเตอร์ +15% ต่อรอบ
- รองรับการสลับ **ช่องบันทึก 3 ช่อง (`S1`, `S2`, `S3`)** พร้อมบันทึกอัตโนมัติผ่าน `localStorage`

## ปุ่มควบคุม & คีย์ลัด (Controls & Hotkeys)

| ปุ่ม / คีย์ลัด | คำสั่ง |
| :--- | :--- |
| `W` / `A` / `S` / `D` หรือปุ่มลูกศร | เดิน / โจมตีประชิด |
| `1` | ใช้สกิลประจำเผ่า |
| `2` – `5` | ใช้สกิลจากแก่นแท้ช่องที่ 1–4 |
| `Q` | ใช้ `Healing Potion` |
| `T` | จุดคบไฟ (`Torch`) |
| `B` | ใช้ผ้าพันแผล (`Bandage`) |
| `I` | เปิด / ปิดหน้าต่างอุปกรณ์ กระเป๋า และสารานุกรม (`LoadoutModal`) |
| `Esc` | ปิดหน้าต่าง Modal ที่เปิดอยู่ |

## การติดตั้งและรันโปรเจกต์ (Getting Started)

```bash
# 1. ติดตั้ง dependencies
npm install

# 2. รันเซิร์ฟเวอร์สำหรับพัฒนา (Development)
npm run dev

# 3. ตรวจสอบ TypeScript และ Build สำหรับ Production
npm run build

# 4. พรีวิวผลลัพธ์จากไฟล์ Build
npm run preview
```

> **หมายเหตุสำหรับ Windows PowerShell**: หากติด Execution Policy สามารถใช้ `npm.cmd run dev` หรือ `npm.cmd run build` แทน `npm` ได้
